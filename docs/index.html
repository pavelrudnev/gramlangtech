Recap

We’ve learnt about the hierarchical organisation of natural-language expressions

  • words
    • consisting of morphemes, organised by dedicated morpheme-ordering rules
  • phrases
    • consisting of words, organised by dedicated word-ordering rules
  • sentences
    • consisting of phrases (and/or other sentences), organised by dedicated rules

We’ve also established that we humans possess cognitive biases favouring the acquisition of hierarchical structure-sensitive rules.

Lemmatisation

removing inflectional morphology to return a word’s ‘basic’ form

import spacy
sp = spacy.load('en_core_web_sm')
for token in ['compute', 'computed', 'computing', 'computer', 'computers']:
    print(token + ' --> ' + sp(token)[0].lemma_)
compute --> compute
computed --> compute
computing --> computing
computer --> computer
computers --> computer

Note that computer does not lemmatise to compute, and nor does computing.

  • compute, computer, computing are all different lexemes
  • spaCy’s lemmatiser only strips inflectional morphology

Stemming

removing what’s probably not a part of a word’s root/stem

import nltk
from nltk.stem.porter import *
stemmer = PorterStemmer()
for token in ['compute', 'computed', 'computing', 'computer', 'computers']:
    print(token + ' --> ' + stemmer.stem(token))
compute --> comput
computed --> comput
computing --> comput
computer --> comput
computers --> comput

We can see that the stemmer strips off both inflectional and derivational morphology off of computed, computer, computing, computers.

computing can be used in at least two ways; what caveat ought to be made, and what assumption does spaCy make?

Automatic inflection

adding inflectional morphology to ‘basic’ word forms

  • Verbal conjugation
  • Nominal inflection
from mlconjug3 import Conjugator
import warnings
warnings.filterwarnings('ignore')

conjugator = Conjugator('en')
verb = conjugator.conjugate("speak")

# Safely find the past tense key
past_tense_key = [k for k in verb.conjug_info['indicative'].keys() if 'past' in k.lower()][0]
form = verb.conjug_info['indicative'][past_tense_key]['1s']

print('speak + indicative past tense --> ' + form)
speak + indicative past tense --> spoke

Say we wanted to have speak appear in the past tense.1

import inflect
p = inflect.engine()
print('tooth' + ' + plural --> ' + p.plural_noun('tooth'))
tooth + plural --> teeth

A few classical-task resources

  • UniMorph
    • collaborative project aiming to improve how NLP handles complex morphology in the world’s languages by creating standardised morphologically annotated datasets
  • Universal Dependencies
    • framework for consistent annotation of grammar (parts of speech, morphological features, syntactic dependencies) currently producing treebanks in ca. 150 languages.

Monolingual and multilingual tokenisers

Bertram’s father-in-law’s just made him a cuppa tea.

Why don’t we try and tokenise it a couple of different ways?

  • BERT

  • XLM-RoBERTa

from transformers import AutoTokenizer

sentences = {
  "English": "Bertram's father-in-law's just made him a cuppa tea.",
}

tok = AutoTokenizer.from_pretrained("bert-base-uncased")
for lang, text in sentences.items():
    print(f"{lang}: {tok.tokenize(text)}")

Syntax and language technology

Sentence parsing

automatic syntactic analysis

classic NLP task

  • input: natural-language text
  • output: syntactic structure
    • constituency structure
    • dependency structure
    • constituency+dependency structure

Berkeley Neural Parser

import stanza

# Download the English model (only needed once)
stanza.download('en', processors='tokenize,pos,constituency')

nlp = stanza.Pipeline(lang='en', processors='tokenize,pos,constituency')
doc = nlp('The time for action is now.')

# Access the constituency tree
tree = doc.sentences[0].constituency
print(tree)
(ROOT (S (NP (NP (DT The) (NN time)) (PP (IN for) (NP (NN action)))) (VP (VBZ is) (ADVP (RB now))) (. .)))

What is required for syntactic parsing?
